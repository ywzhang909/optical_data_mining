## 一、二维空间均匀度的核心指标

### 1.1 直接基于强度分布的指标

| 指标                       | 公式                                               | 物理意义            | 适用场景                 |
| -------------------------- | -------------------------------------------------- | ------------------- | ------------------------ |
| **全局均匀度**       | $U_{global} = \frac{\min I}{\max I}$             | 全图最小/最大强度比 | 快速评估，但对异常值敏感 |
| **平顶区均匀度**     | $U_{flat} = \frac{\mu - k\sigma}{\mu + k\sigma}$ | 平顶区均值±标准差  | 需先定义平顶区域         |
| **变异系数**         | $CV = \frac{\sigma}{\mu}$                        | 相对标准差          | 越小越均匀               |
| **非均匀度**         | $NU = \frac{I_{max}-I_{min}}{I_{max}+I_{min}}$   | 峰谷相对差          | 0=完全均匀，1=极端不均匀 |
| **均方根偏差**       | $RMSD = \sqrt{\frac{1}{N}\sum(I_i - \bar{I})^2}$ | 绝对波动量          | 与强度量级相关           |
| **归一化均方根偏差** | $NRMSD = \frac{RMSD}{\bar{I}}$                   | 相对波动量          | 跨图像可比               |

### 1.2 基于理想模型的指标（FTL 扩展）

| 指标                     | 公式                                                   | 物理意义               |
| ------------------------ | ------------------------------------------------------ | ---------------------- |
| **FTL 拟合残差图** | $\Delta I(x,y) = I_{meas} - I_{FTL}(x,y)$            | 逐点偏离理想平顶的程度 |
| **相对残差**       | $\epsilon(x,y) = \frac{\Delta I(x,y)}{I_{FTL}(x,y)}$ | 百分比偏差             |
| **残差标准差**     | $\sigma_{res} = \text{std}(\Delta I)$                | 整体拟合质量           |
| **结构相似度**     | $SSIM(I_{meas}, I_{FTL})$                            | 与理想模型的感知相似度 |

### 1.3 基于频域/结构的指标

| 指标                   | 公式                                                        | 物理意义               |
| ---------------------- | ----------------------------------------------------------- | ---------------------- |
| **功率谱密度**   | $PSD(f_x, f_y) = |\mathcal{F}\{I(x,y)\}|^2$               | 不同空间频率的能量分布 |
| **中频粗糙度**   | $\sigma_{mid} = \int_{f_{low}}^{f_{high}} PSD(f) df$      | 平顶区中尺度起伏       |
| **高频噪声**     | $\sigma_{high} = \int_{f_{high}}^{\infty} PSD(f) df$      | 颗粒噪声/散斑          |
| **梯度幅值**     | $|\nabla I| = \sqrt{(\partial_x I)^2 + (\partial_y I)^2}$ | 边缘清晰度与内部平滑度 |
| **拉普拉斯能量** | $\sum |\nabla^2 I|^2$                                     | 二阶平滑度             |

## 二、完整实现代码

```python
import numpy as np
import cv2
from scipy import ndimage
from scipy.fft import fft2, fftshift
from scipy.stats import binned_statistic
from typing import Optional, Literal, Tuple
import warnings


class Pupil2DUniformity:
    """
    二维空间光瞳均匀度分析器
    支持：直接统计指标、FTL 模型残差、频域分析、局部缺陷检测
    """
  
    def __init__(self, image: np.ndarray, pixel_size: float = 1.0):
        self.img = np.asarray(image, dtype=np.float64)
        self.h, self.w = self.img.shape
        self.pixel_size = pixel_size
      
        # 预处理
        self._preprocess()
      
        # 极坐标网格
        self._build_polar_grid()
  
    def _preprocess(self):
        """背景扣除与归一化"""
        # 背景估计：四角中位数
        c = max(self.h, self.w) // 10
        corners = [
            self.img[:c, :c], self.img[:c, -c:],
            self.img[-c:, :c], self.img[-c:, -c:]
        ]
        self.bg = np.median([np.median(c) for c in corners])
        self.img_bg = np.clip(self.img - self.bg, 0, None)
      
        # 归一化
        self.img_norm = self.img_bg / (np.max(self.img_bg) + 1e-10)
      
        # 中心
        y, x = np.indices((self.h, self.w))
        total = np.sum(self.img_bg)
        if total > 0:
            self.cx = np.sum(x * self.img_bg) / total
            self.cy = np.sum(y * self.img_bg) / total
        else:
            self.cx, self.cy = self.w / 2.0, self.h / 2.0
      
        # 径向距离
        self.R = np.sqrt((x - self.cx)**2 + (y - self.cy)**2)
        self.Theta = np.arctan2(y - self.cy, x - self.cx)
  
    def _build_polar_grid(self):
        """构建极坐标分箱网格"""
        self.R_max = min(self.h, self.w) / 2 * 0.85
        self.n_r = 100
        self.n_theta = 72  # 5° 分辨率
      
        self.r_edges = np.linspace(0, self.R_max, self.n_r + 1)
        self.theta_edges = np.linspace(-np.pi, np.pi, self.n_theta + 1)
      
        # 2D 分箱
        self.I_polar, _, _ = binned_statistic_2d(
            self.R.ravel(), self.Theta.ravel(), self.img_norm.ravel(),
            statistic='mean', bins=[self.r_edges, self.theta_edges]
        )
        # 处理 NaN
        self.I_polar = np.nan_to_num(self.I_polar, nan=0)
  
    # ==================== 1. 直接统计指标 ====================
  
    def global_uniformity(self) -> dict:
        """全局均匀度"""
        I = self.img_norm[self.img_norm > 0.01]  # 排除暗背景
      
        return {
            'min_max_ratio': float(np.min(I) / np.max(I)),
            'cv': float(np.std(I) / np.mean(I)),
            'non_uniformity': float((np.max(I) - np.min(I)) / (np.max(I) + np.min(I))),
            'rmsd': float(np.sqrt(np.mean((I - np.mean(I))**2))),
            'nrmsd': float(np.sqrt(np.mean((I - np.mean(I))**2)) / np.mean(I)),
            'skewness': float(np.mean((I - np.mean(I))**3) / np.std(I)**3),
            'kurtosis': float(np.mean((I - np.mean(I))**4) / np.std(I)**4 - 3),
        }
  
    def annular_uniformity(self, 
                          r_inner_ratio: float = 0.2,
                          r_outer_ratio: float = 0.8) -> dict:
        """
        环形区域（平顶区）均匀度
        """
        r_inner = self.R_max * r_inner_ratio
        r_outer = self.R_max * r_outer_ratio
      
        mask = (self.R >= r_inner) & (self.R <= r_outer)
        I_flat = self.img_norm[mask]
      
        if len(I_flat) == 0:
            return {}
      
        return {
            'region': f'{r_inner_ratio*100:.0f}%-{r_outer_ratio*100:.0f}% R_max',
            'mean': float(np.mean(I_flat)),
            'std': float(np.std(I_flat)),
            'cv': float(np.std(I_flat) / np.mean(I_flat)),
            'min_max_ratio': float(np.min(I_flat) / np.max(I_flat)),
            'percentile_90_10': float(
                np.percentile(I_flat, 90) / np.percentile(I_flat, 10)
            ),
            'fraction_within_10pct': float(
                np.sum(np.abs(I_flat - np.mean(I_flat)) < 0.1 * np.mean(I_flat)) / len(I_flat)
            ),
        }
  
    def radial_gradient_uniformity(self) -> dict:
        """
        径向梯度均匀度：评估从中心到边缘的过渡质量
        """
        # 径向平均
        r_centers = (self.r_edges[:-1] + self.r_edges[1:]) / 2
        I_radial = np.mean(self.I_polar, axis=1)  # 对方位角平均
      
        # 计算径向梯度
        dI_dr = np.gradient(I_radial, r_centers)
        d2I_dr2 = np.gradient(dI_dr, r_centers)
      
        # 找到平顶区（梯度接近0）
        flat_mask = np.abs(dI_dr) < 0.01
      
        return {
            'r_profile': r_centers.tolist(),
            'I_profile': I_radial.tolist(),
            'dI_dr': dI_dr.tolist(),
            'd2I_dr2': d2I_dr2.tolist(),
            'flat_region_extent': float(np.sum(flat_mask) / len(flat_mask)),
            'max_gradient': float(np.max(np.abs(dI_dr))),
            'edge_steepness': float(np.max(np.abs(dI_dr))),  # 边缘最大梯度
        }
  
    # ==================== 2. FTL 模型残差分析 ====================
  
    def ftl_residual_analysis(self, 
                              fit_mode: Literal['global', 'per_angle', 'elliptical'] = 'per_angle'
                             ) -> dict:
        """
        FTL 模型二维残差分析
        """
        from scipy.optimize import curve_fit
      
        def ftl_2d(coords, I0, R_FL, q):
            """向量化 FTL 函数"""
            R = coords
            x = R / R_FL
            x = np.clip(x, 0, 1e3)
            with np.errstate(over='ignore'):
                return I0 / ((1 + x**q)**(1 + 2/q))
      
        if fit_mode == 'global':
            # 全局径向拟合
            r_flat = self.R.ravel()
            I_flat = self.img_norm.ravel()
          
            # 采样加速
            idx = np.random.choice(len(r_flat), min(50000, len(r_flat)), replace=False)
            popt, _ = curve_fit(
                ftl_2d, r_flat[idx], I_flat[idx],
                p0=[1.0, self.R_max * 0.4, 6.0],
                bounds=([0.1, 1, 0.5], [5.0, self.R_max, 50])
            )
            I0_fit, R_FL_fit, q_fit = popt
          
            # 全局残差
            I_model = ftl_2d(self.R, I0_fit, R_FL_fit, q_fit)
          
        elif fit_mode == 'per_angle':
            # 逐角度拟合，构建角度相关模型
            I_model = np.zeros_like(self.img_norm)
          
            dtheta = 2 * np.pi / 36
            for i in range(36):
                theta_c = -np.pi + i * dtheta
                theta_min = theta_c - dtheta / 2
                theta_max = theta_c + dtheta / 2
              
                # 扇区掩膜
                if theta_min < -np.pi:
                    mask = ((self.Theta >= theta_min + 2*np.pi) | 
                            (self.Theta < theta_max))
                elif theta_max > np.pi:
                    mask = ((self.Theta >= theta_min) | 
                            (self.Theta < theta_max - 2*np.pi))
                else:
                    mask = (self.Theta >= theta_min) & (self.Theta < theta_max)
              
                if np.sum(mask) < 100:
                    continue
              
                r_sector = self.R[mask].ravel()
                I_sector = self.img_norm[mask].ravel()
              
                try:
                    popt, _ = curve_fit(
                        ftl_2d, r_sector, I_sector,
                        p0=[1.0, self.R_max * 0.4, 6.0],
                        bounds=([0.1, 1, 0.5], [5.0, self.R_max, 50]),
                        maxfev=3000
                    )
                    I0_a, R_FL_a, q_a = popt
                except RuntimeError:
                    I0_a, R_FL_a, q_a = 1.0, self.R_max * 0.4, 6.0
              
                I_model[mask] = ftl_2d(self.R[mask], I0_a, R_FL_a, q_a)
          
            # 未覆盖区域用全局平均
            I_model[I_model == 0] = np.mean(self.img_norm)
          
            I0_fit = R_FL_fit = q_fit = None  # 多参数，不返回单一值
      
        else:  # elliptical
            # 椭圆变形 FTL
            def ftl_elliptical(coords, I0, a, b, phi, q):
                R, Theta = coords
                # 椭圆等效半径
                cos_t = np.cos(Theta - phi)
                sin_t = np.sin(Theta - phi)
                R_eff = a * b / np.sqrt((b * cos_t)**2 + (a * sin_t)**2)
                x = R / R_eff
                x = np.clip(x, 0, 1e3)
                return I0 / ((1 + x**q)**(1 + 2/q))
          
            coords = (self.R.ravel(), self.Theta.ravel())
            idx = np.random.choice(len(coords[0]), min(50000, len(coords[0])), replace=False)
          
            popt, _ = curve_fit(
                lambda c, I0, a, b, phi, q: ftl_elliptical(c, I0, a, b, phi, q),
                (coords[0][idx], coords[1][idx]),
                self.img_norm.ravel()[idx],
                p0=[1.0, self.R_max * 0.5, self.R_max * 0.4, 0, 6.0],
                bounds=([0.1, 1, 1, -np.pi, 0.5], [5.0, self.R_max, self.R_max, np.pi, 50])
            )
            I0_fit, a_fit, b_fit, phi_fit, q_fit = popt
          
            I_model = ftl_elliptical((self.R, self.Theta), I0_fit, a_fit, b_fit, phi_fit, q_fit)
      
        # 残差计算
        residual = self.img_norm - I_model
        relative_residual = residual / (I_model + 1e-10)
      
        return {
            'fit_params': {
                'I0': float(I0_fit) if I0_fit is not None else None,
                'R_FL': float(R_FL_fit) if R_FL_fit is not None else None,
                'q': float(q_fit) if q_fit is not None else None,
            },
            'residual_map': residual,
            'relative_residual_map': relative_residual,
            'residual_stats': {
                'mean': float(np.mean(residual)),
                'std': float(np.std(residual)),
                'max_abs': float(np.max(np.abs(residual))),
                'rms': float(np.sqrt(np.mean(residual**2))),
            },
            'relative_residual_stats': {
                'mean': float(np.mean(relative_residual)),
                'std': float(np.std(relative_residual)),
                'max_abs': float(np.max(np.abs(relative_residual))),
                'fraction_within_5pct': float(np.sum(np.abs(relative_residual) < 0.05) / residual.size),
                'fraction_within_10pct': float(np.sum(np.abs(relative_residual) < 0.10) / residual.size),
            },
            'model_map': I_model,
        }
  
    # ==================== 3. 频域分析 ====================
  
    def frequency_analysis(self) -> dict:
        """
        二维频域分析：识别周期性结构（散斑、干涉条纹等）
        """
        # 加窗减少频谱泄漏
        window = np.outer(np.hanning(self.h), np.hanning(self.w))
        I_windowed = self.img_norm * window
      
        # 2D FFT
        spectrum = fftshift(fft2(I_windowed))
        psd = np.abs(spectrum)**2
      
        # 频率坐标
        fx = np.fft.fftshift(np.fft.fftfreq(self.w, self.pixel_size))
        fy = np.fft.fftshift(np.fft.fftfreq(self.h, self.pixel_size))
        FX, FY = np.meshgrid(fx, fy)
        F_mag = np.sqrt(FX**2 + FY**2)
      
        # 径向平均 PSD
        f_bins = np.linspace(0, np.max(F_mag), 50)
        psd_radial, _, _ = binned_statistic(
            F_mag.ravel(), psd.ravel(), statistic='mean', bins=f_bins
        )
        f_centers = (f_bins[:-1] + f_bins[1:]) / 2
      
        # 分频段能量
        df = f_centers[1] - f_centers[0] if len(f_centers) > 1 else 1
        total_energy = np.sum(psd_radial[~np.isnan(psd_radial)]) * df
      
        # 定义频段
        f_nyquist = np.max(f_mag) / 2
        low_freq = f_centers < f_nyquist * 0.1
        mid_freq = (f_centers >= f_nyquist * 0.1) & (f_centers < f_nyquist * 0.5)
        high_freq = f_centers >= f_nyquist * 0.5
      
        return {
            'psd_2d': psd,
            'psd_radial': {
                'f': f_centers.tolist(),
                'psd': np.nan_to_num(psd_radial).tolist(),
            },
            'frequency_bands': {
                'low_freq_energy': float(np.sum(psd_radial[low_freq]) * df / total_energy) if total_energy > 0 else 0,
                'mid_freq_energy': float(np.sum(psd_radial[mid_freq]) * df / total_energy) if total_energy > 0 else 0,
                'high_freq_energy': float(np.sum(psd_radial[high_freq]) * df / total_energy) if total_energy > 0 else 0,
            },
            'dominant_frequency': {
                'f_peak': float(f_centers[np.argmax(psd_radial)]) if len(f_centers) > 0 else 0,
                'psd_peak': float(np.max(psd_radial)),
            },
        }
  
    # ==================== 4. 局部缺陷检测 ====================
  
    def local_defect_detection(self,
                               method: Literal['threshold', 'statistical', 'gradient'] = 'statistical'
                              ) -> dict:
        """
        检测局部缺陷：热点、暗区、边缘缺口
        """
        if method == 'threshold':
            # 基于全局阈值的简单检测
            mean_I = np.mean(self.img_norm)
            std_I = np.std(self.img_norm)
          
            hot_spots = self.img_norm > mean_I + 3 * std_I
            cold_spots = self.img_norm < mean_I - 3 * std_I
          
        elif method == 'statistical':
            # 局部统计异常检测（滑动窗口）
            from scipy.ndimage import uniform_filter
          
            local_mean = uniform_filter(self.img_norm, size=15)
            local_std = np.sqrt(uniform_filter(self.img_norm**2, size=15) - local_mean**2)
          
            z_score = (self.img_norm - local_mean) / (local_std + 1e-10)
            hot_spots = z_score > 3
            cold_spots = z_score < -3
          
        else:  # gradient
            # 梯度异常检测
            gy, gx = np.gradient(self.img_norm)
            grad_mag = np.sqrt(gx**2 + gy**2)
          
            hot_spots = grad_mag > np.percentile(grad_mag, 99)
            cold_spots = np.zeros_like(hot_spots)  # 梯度不检测暗区
      
        # 连通域分析
        from scipy import ndimage as ndi
      
        hot_labels, hot_n = ndi.label(hot_spots)
        cold_labels, cold_n = ndi.label(cold_spots)
      
        hot_regions = []
        for i in range(1, hot_n + 1):
            mask = hot_labels == i
            if np.sum(mask) < 10:  # 过滤噪声
                continue
            hot_regions.append({
                'area_pixels': int(np.sum(mask)),
                'max_intensity': float(np.max(self.img_norm[mask])),
                'centroid': (float(np.mean(np.where(mask)[1])), 
                            float(np.mean(np.where(mask)[0]))),
            })
      
        cold_regions = []
        for i in range(1, cold_n + 1):
            mask = cold_labels == i
            if np.sum(mask) < 10:
                continue
            cold_regions.append({
                'area_pixels': int(np.sum(mask)),
                'min_intensity': float(np.min(self.img_norm[mask])),
                'centroid': (float(np.mean(np.where(mask)[1])), 
                            float(np.mean(np.where(mask)[0]))),
            })
      
        return {
            'method': method,
            'hot_spots': {
                'n_regions': len(hot_regions),
                'regions': hot_regions,
                'total_area_ratio': float(np.sum(hot_spots) / self.img_norm.size),
            },
            'cold_spots': {
                'n_regions': len(cold_regions),
                'regions': cold_regions,
                'total_area_ratio': float(np.sum(cold_spots) / self.img_norm.size),
            },
            'defect_map': hot_spots.astype(int) - cold_spots.astype(int),  # +1=热点, -1=暗区, 0=正常
        }
  
    # ==================== 5. 综合报告 ====================
  
    def full_analysis(self) -> dict:
        """执行全部分析并返回综合报告"""
        return {
            'image_info': {
                'shape': (self.h, self.w),
                'pixel_size_um': self.pixel_size,
                'center': (float(self.cx), float(self.cy)),
            },
            'global_uniformity': self.global_uniformity(),
            'annular_uniformity': self.annular_uniformity(),
            'radial_gradient': self.radial_gradient_uniformity(),
            'ftl_residual': self.ftl_residual_analysis(fit_mode='per_angle'),
            'frequency': self.frequency_analysis(),
            'local_defects': self.local_defect_detection(method='statistical'),
        }


# ==================== 可视化 ====================

def visualize_2d_uniformity(analysis: dict, 
                            pupil: 'Pupil2DUniformity',
                            save_path: Optional[str] = None):
    """
    二维均匀度分析可视化
    """
    import matplotlib.pyplot as plt
    from matplotlib.colors import SymLogNorm, TwoSlopeNorm
  
    fig = plt.figure(figsize=(18, 14))
    gs = fig.add_gridspec(3, 4, hspace=0.35, wspace=0.35)
  
    # 1. 原始图像
    ax1 = fig.add_subplot(gs[0, 0])
    im1 = ax1.imshow(pupil.img_norm, cmap='hot', origin='lower')
    ax1.set_title('Normalized Intensity')
    plt.colorbar(im1, ax=ax1, fraction=0.046)
  
    # 2. FTL 残差图
    ftl = analysis['ftl_residual']
    ax2 = fig.add_subplot(gs[0, 1])
    residual = ftl['residual_map']
    vmax = np.percentile(np.abs(residual), 99)
    im2 = ax2.imshow(residual, cmap='RdBu_r', origin='lower',
                     vmin=-vmax, vmax=vmax, norm=TwoSlopeNorm(vcenter=0))
    ax2.set_title(f'FTL Residual (RMS={ftl["residual_stats"]["rms"]:.4f})')
    plt.colorbar(im2, ax=ax2, fraction=0.046)
  
    # 3. 相对残差图
    ax3 = fig.add_subplot(gs[0, 2])
    rel_res = ftl['relative_residual_map']
    vmax_rel = min(np.percentile(np.abs(rel_res), 99), 0.5)
    im3 = ax3.imshow(rel_res, cmap='RdBu_r', origin='lower',
                     vmin=-vmax_rel, vmax=vmax_rel, norm=TwoSlopeNorm(vcenter=0))
    ax3.set_title(f'Relative Residual\n(±5%: {ftl["relative_residual_stats"]["fraction_within_5pct"]*100:.1f}%)')
    plt.colorbar(im3, ax=ax3, fraction=0.046)
  
    # 4. 局部缺陷图
    ax4 = fig.add_subplot(gs[0, 3])
    defects = analysis['local_defects']
    defect_map = defects['defect_map']
    im4 = ax4.imshow(defect_map, cmap='RdYlGn', origin='lower', vmin=-1, vmax=1)
```

## 三、关键指标速查

| 应用场景       | 推荐指标                                                            | 判断标准                     |
| -------------- | ------------------------------------------------------------------- | ---------------------------- |
| 快速整体评估   | `global_uniformity['cv']`                                         | < 5% 优秀，< 10% 良好        |
| 平顶光斑质量   | `annular_uniformity['fraction_within_10pct']`                     | > 90% 优秀                   |
| 与理想模型偏离 | `ftl_residual['relative_residual_stats']['fraction_within_5pct']` | > 80% 优秀                   |
| 边缘质量       | `radial_gradient['edge_steepness']`                               | 越大越陡峭（需结合设计目标） |
| 散斑/干涉检测  | `frequency['high_freq_energy']`                                   | 越低越好                     |
| 局部缺陷筛查   | `local_defects['hot_spots']['n_regions']`                         | 0 为理想                     |
| 像散检测       | 极坐标图$n=2$ 分量                                                | FFT 幅度显著提示像散         |

二维分析相比逐角度分析的优势在于：**能定位缺陷的空间位置**（如"右上角有热点"），而不仅仅是"某个角度不均匀"。
