## 一、适用范围与前提假设

### 1.1 适用场景

| 场景           | 分析目标         | 关键指标                       |
| -------------- | ---------------- | ------------------------------ |
| SLM光束整形    | 评估平顶光斑质量 | $P_{5\%}$, $q$, $R_{FL}$ |
| 自适应光学闭环 | 监测波前校正效果 | 残差周期性,$P_{5\%}$趋势     |
| 激光加工系统   | 验收光束均匀性   | 平顶区达标率, 边缘陡度         |
| 光学装调       | 定位像差来源     | 方位角FFT, 椭圆参数            |
| 光刻照明       | 掩膜面照明均匀性 | 二维空间CV, 局部缺陷           |

### 1.2 前提假设

| 假设                  | 说明                   | 违反时的处理                        |
| --------------------- | ---------------------- | ----------------------------------- |
| 旋转对称性（基础FTL） | 光斑近似轴对称         | 采用逐角度FTL或椭圆FTL扩展          |
| 单一横截面            | 分析特定z平面          | 需多平面数据或传播模型（见附录A.1） |

| 近轴近似              | 光斑尺寸远大于波长     | 大NA系统需修正                      |
| 能量有限性            | 光斑能量集中于有限区域 | 定义有效分析区域$\Omega$          |

## 二、数据预处理流程

### 2.1 输入数据要求

| 参数         | 要求                | 备注                       |
| ------------ | ------------------- | -------------------------- |
| 图像格式     | 单通道灰度图        | 彩色图需先转换             |
| 动态范围     | 建议≥12 bit        | 低动态范围会压缩平顶区细节 |
| 信噪比       | SNR > 30 dB         | 低于此阈值需增强处理       |
| 采样率       | ≥ 4 pixel / FWHM   | 奈奎斯特采样准则           |
| 背景区域     | 图像边缘≥10%为背景 | 用于背景估计               |
| 像素物理尺寸 | 需标定（μm/pixel） | 用于物理量反算             |

### 2.2 预处理步骤

**Step 1: 背景估计与扣除**

采用多策略融合估计背景，避免光斑能量泄漏影响：

| 方法         | 适用场景   | 计算公式                                                            |
| ------------ | ---------- | ------------------------------------------------------------------- |
| 四角中位数法 | 背景均匀   | $B = \text{median}\left(\bigcup_{i=1}^{4} \text{corner}_i\right)$ |
| 形态学开运算 | 背景渐变   | $B = \phi_{SE}(I)$，其中 $SE$ 为大于光斑的椭圆结构元            |
| 百分位数法   | 光斑占比大 | $B = P_{10}(I)$，即图像10%分位数                                  |
| 自适应背景   | 复杂背景   | 大尺度高斯滤波（$\sigma = 50$ pixel）                             |

最终背景取各方法估计的最小值（保守估计）：

$$
B_{final} = \min(B_{corner}, B_{morph}, B_{percentile})
$$

扣除后图像：

$$
I_{bg}(x,y) = \max(I_{raw}(x,y) - B_{final}, 0)
$$

**Step 2: 噪声抑制**

| 噪声类型     | 处理方法            | 参数建议                                            |
| ------------ | ------------------- | --------------------------------------------------- |
| 高频随机噪声 | 高斯滤波            | $\sigma = 1.0 \sim 2.0$ pixel                     |
| 散粒噪声     | 非局部均值去噪      | $h = 10, \text{template} = 7, \text{search} = 21$ |
| 坏点/热像素  | 中值滤波检测 + 替换 | 3×3窗口，MAD异常值检测                             |
| 固定图案噪声 | 平场校正            | 需提前采集暗场/平场                                 |
| 条纹噪声     | 频域陷波滤波        | 针对特定频率成分                                    |

**Step 3: 归一化**

采用峰值归一化，便于与理想模型对比：

$$
I_{norm}(x,y) = \frac{I_{denoised}(x,y)}{\max(I_{denoised})}
$$

保留原始峰值 $I_{peak}$ 用于后续物理量反算：

$$
I_{phys}(x,y) = I_{norm}(x,y) \times I_{peak} \quad [\text{counts 或 W/m}^2]
$$

**Step 4: 有效区域定义**

以质心为中心，按能量集中度定义分析区域：

$$
\Omega = \{(x,y) \mid R(x,y) \leq R_{max}\}
$$

其中 $R_{max} = 0.85 \times \min(H,W)/2$，覆盖约95%光斑能量。

**Step 5: 质量预检**

在正式分析前进行快速质量评估：

| 检查项         | 判据                  | 失败处理               |
| -------------- | --------------------- | ---------------------- |
| 信噪比         | SNR > 30 dB           | 增加平均次数或延长曝光 |
| 动态范围利用率 | 峰值 < 90% 满阱       | 调整曝光时间           |
| 饱和检测       | 饱和像素 < 0.1%       | 降低曝光，重新采集     |
| 背景占比       | 背景标准差 < 峰值/100 | 改善环境杂散光         |
| 光斑完整性     | 光斑完全在视场内      | 调整光路或相机位置     |

## 三、光斑中心精确定位

### 3.1 迭代加权质心法

初始估计：

$$
x_c^{(0)} = \frac{W}{2}, \quad y_c^{(0)} = \frac{H}{2}
$$

迭代更新（$k = 0, 1, \dots, N-1$）：

$$
w^{(k)}(x,y) = \exp\left[-\left(\frac{R^{(k)}(x,y)}{0.5 R_{max}}\right)^2\right]
$$

$$
x_c^{(k+1)} = \frac{\sum x \cdot I_{norm}(x,y) \cdot w^{(k)}(x,y)}{\sum I_{norm}(x,y) \cdot w^{(k)}(x,y)}
$$

$$
y_c^{(k+1)} = \frac{\sum y \cdot I_{norm}(x,y) \cdot w^{(k)}(x,y)}{\sum I_{norm}(x,y) \cdot w^{(k)}(x,y)}
$$

其中 $R^{(k)}(x,y) = \sqrt{(x-x_c^{(k)})^2 + (y-y_c^{(k)})^2}$。

**收敛判据**：$|x_c^{(k+1)} - x_c^{(k)}| < 0.01$ pixel，通常 $N=3 \sim 5$ 次迭代。

### 3.2 亚像素精度验证

通过径向对称性检验中心质量：

$$
S_{sym} = \frac{\sum_{\theta} \left| I(r, \theta) - I(r, \theta+\pi) \right|}{\sum_{\theta} I(r, \theta)}
$$

$S_{sym} < 0.05$ 表明中心定位准确。

### 3.3 中心偏移对均匀度评估的影响

| 偏移量        | 影响                 | 补偿方法           |
| ------------- | -------------------- | ------------------ |
| < 0.5 pixel   | 可忽略               | 无需处理           |
| 0.5 ~ 2 pixel | 引入虚假方位角不均匀 | 亚像素精化         |
| > 2 pixel     | 严重扭曲径向分布     | 重新定位，检查光路 |

## 四、FTL理想模型构建

### 4.1 标准FTL模型

$$
I_{FTL}(R) = \frac{I_0}{\left[1 + \left(\frac{R}{R_{FL}}\right)^q\right]^{1 + \frac{2}{q}}}
$$

| 参数       | 物理意义     | 典型范围              | 设计关联               |
| ---------- | ------------ | --------------------- | ---------------------- |
| $I_0$    | 中心峰值强度 | 归一化后$\approx 1$ | 与入射功率成正比       |
| $R_{FL}$ | 特征半径     | 与光斑半高宽相关      | 决定光斑整体尺度       |
| $q$      | 平顶阶数     | $2 \sim 20$         | 越大顶部越平、边缘越陡 |

**参数极限行为**：

- $q \to \infty$：理想硬边平顶（top-hat）
- $q = 2$：退化为洛伦兹线型，中心尖峰
- $q \approx 6 \sim 10$：实用平顶光束典型值

### 4.2 全局拟合

**数据准备**：径向分箱平均

- 分箱数：$N_{bin} = 100 \sim 200$
- 最大半径：$R_{fit} = R_{max}$
- 统计量：均值（抗噪声）或中位数（抗饱和）

**初始猜测**：

$$
I_0^{(0)} = \max(\bar{I}(r)), \quad R_{FL}^{(0)} = r\big|_{\bar{I} = I_0/2}, \quad q^{(0)} = 6.0
$$

**非线性最小二乘**：

$$
\min_{I_0, R_{FL}, q} \sum_{i=1}^{N_{bin}} \frac{\left[\bar{I}(r_i) - I_{FTL}(r_i; I_0, R_{FL}, q)\right]^2}{\sigma_i^2}
$$

其中 $\sigma_i$ 为第 $i$ 个环带的标准差，作为权重。

**约束条件**：

$$
I_0 > 0, \quad R_{FL} > 1 \text{ pixel}, \quad q > 0.5
$$

**拟合质量评估**：

- 决定系数 $R^2 > 0.95$：模型适用
- $R^2 < 0.90$：光斑可能非FTL型，需检查模型或改用其他模型

### 4.3 逐角度FTL扩展（AD-FTL）

当光斑存在方位角不对称时，将 $R_{FL}$ 推广为 $\theta$ 的函数：

$$
I_{AD}(R, \theta) = \frac{I_0}{\left[1 + \left(\frac{R}{R_{FL}(\theta)}\right)^q\right]^{1 + \frac{2}{q}}}
$$

**扇区划分**：

- 方位角分辨率：$N_{\theta} = 36$（10°间隔）
- 扇区角宽度：$\Delta\theta = 15^\circ \sim 20^\circ$（允许重叠提升鲁棒性）
- 耦合拟合：固定 $I_0$ 和 $q$，仅优化 $R_{FL}(\theta)$

**椭圆约束模型**（像散主导场景）：

$$
\frac{1}{R_{FL}^2(\theta)} = \frac{\cos^2(\theta-\phi)}{a^2} + \frac{\sin^2(\theta-\phi)}{b^2}
$$

参数：$a$（长半轴）、$b$（短半轴）、$\phi$（方向角）。

### 4.4 模型选择决策树

```
开始
  │
  ├─ 光斑近似圆对称？ ──是──→ 全局FTL拟合
  │       │
  │       否
  │       │
  ├─ 存在明显椭圆变形？ ──是──→ 椭圆约束AD-FTL
  │       │
  │       否
  │       │
  └─ 复杂方位角结构？ ──是──→ 逐角度AD-FTL
          │
          否
          │
          └─ 检查是否为非FTL型光斑（高斯/贝塞尔等）
```

## 五、残差计算与统计指标

### 5.1 残差定义

| 类型     | 公式                                                         | 适用场景                     | 颜色映射           |
| -------- | ------------------------------------------------------------ | ---------------------------- | ------------------ |
| 绝对残差 | $\Delta I(x,y) = I_{meas} - I_{FTL}$                       | 定位缺陷位置                 | diverging（红蓝）  |
| 相对残差 | $\epsilon(x,y) = \frac{\Delta I(x,y)}{I_{FTL}(x,y)}$       | 消除径向梯度，量化百分比偏差 | diverging（红蓝）  |
| 对数残差 | $\delta_{log}(x,y) = \log_{10}I_{meas} - \log_{10}I_{FTL}$ | 大动态范围，强调低强度区     | diverging（紫绿）  |
| 符号残差 | $\text{sgn}(\Delta I) \cdot |\epsilon                        | $                            | 同时显示方向和幅度 |

### 5.2 分区域统计

将分析区域 $\Omega$ 划分为三个子区域：

| 区域   | 定义                                 | 物理意义                   | 关键指标       |
| ------ | ------------------------------------ | -------------------------- | -------------- |
| 中心区 | $R < 0.3 R_{max}$                  | 峰值/凹陷检测              | 中心强度一致性 |
| 平顶区 | $0.3 R_{max} \leq R < 0.7 R_{max}$ | **均匀度核心评估区** | $P_{5\%}$    |
| 边缘区 | $R \geq 0.7 R_{max}$               | 边缘陡度、拖尾评估         | 边缘过渡宽度   |

每个区域计算：

| 指标                 | 公式                                                                          | 判读标准               |
| -------------------- | ----------------------------------------------------------------------------- | ---------------------- |
| 平均绝对残差         | $\langle|\Delta I|\rangle = \frac{1}{N}\sum|\Delta I_i                        | $                      |
| 残差标准差           | $\sigma_{\Delta I} = \sqrt{\frac{1}{N}\sum(\Delta I_i - \bar{\Delta I})^2}$ | 反映波动幅度           |
| RMS残差              | $RMS = \sqrt{\frac{1}{N}\sum(\Delta I_i)^2}$                                | 综合偏离量             |
| 最大绝对残差         | $\max|\Delta I                                                                | $                      |
| 相对残差均值         | $\langle|\epsilon|\rangle$                                                  | 百分比偏离             |
| 相对残差标准差       | $\sigma_{\epsilon}$                                                         | 归一化波动             |
| **容差达标率** | $P_{th} = \frac{1}{N}\sum\mathbb{1}(|\epsilon_i| < th)$                     | **核心验收指标** |

### 5.3 核心验收指标

| 容差阈值       | 指标名称              | 优秀标准        | 良好标准        | 合格标准        | 不合格           |
| -------------- | --------------------- | --------------- | --------------- | --------------- | ---------------- |
| ±2%           | $P_{2\%}$           | > 90%           | > 80%           | > 60%           | ≤ 60%           |
| **±5%** | **$P_{5\%}$** | **> 95%** | **> 85%** | **> 70%** | **≤ 70%** |
| ±10%          | $P_{10\%}$          | > 99%           | > 95%           | > 85%           | ≤ 85%           |

**综合评级**：

- **EXCELLENT**：$P_{5\%} > 95\%$ 且 $\sigma_{\epsilon} < 0.03$
- **GOOD**：$P_{5\%} > 85\%$ 且 $\sigma_{\epsilon} < 0.05$
- **FAIR**：$P_{5\%} > 70\%$ 且 $\sigma_{\epsilon} < 0.08$
- **POOR**：$P_{5\%} \leq 70\%$ 或 $\sigma_{\epsilon} \geq 0.08$

### 5.4 残差空间分布特征

| 残差模式           | 可能原因                        | 诊断方法           |
| ------------------ | ------------------------------- | ------------------ |
| 中心凹陷（负残差） | 中心相位缺陷、SLM中心响应非线性 | 检查中心区域放大图 |
| 环形热点（正残差） | 衍射环、干涉条纹                | 极坐标残差图       |
| 扇形分布           | 像散、彗差                      | 方位角FFT分析      |
| 随机斑点           | 散斑噪声、颗粒噪声              | 频域PSD分析        |
| 边缘拖尾（正残差） | 衍射极限、模型q值低估           | 边缘区径向剖面     |
| 对角线分布         | 探测器串扰、光学元件应力        | 旋转图像验证       |

## 六、方位角周期性分析

### 6.1 FFT周期检测

对 $R_{FL}(\theta)$ 或角度平均残差做FFT：

$$
\tilde{R}_{FL}(n) = \text{FFT}\{R_{FL}(\theta_k)\}
$$

| 周期成分$n$ | 光学像差类型                             | 物理来源                 | 补偿策略             |
| ------------- | ---------------------------------------- | ------------------------ | -------------------- |
| $n=1$       | 倾斜（Tip/Tilt）                         | 光束入射角偏移           | 调整入射角度         |
| $n=2$       | **像散（Astigmatism）**            | 柱面像差、非对称光学元件 | 柱面镜补偿或SLM加载  |
| $n=3$       | **彗差（Coma）/三叶草（Trefoil）** | 离轴像差、装调误差       | 调整光路中心         |
| $n=4$       | 四叶草（Quatrefoil）                     | 高阶像差、支撑应力       | 泽尼克模式校正       |
| $n \geq 5$  | 高阶像差                                 | 复杂波前畸变             | 自适应光学或更换元件 |

### 6.2 椭圆参数提取

若 $n=2$ 成分显著，提取椭圆参数：

| 参数   | 公式                       | 物理意义                    |
| ------ | -------------------------- | --------------------------- |
| 长半轴 | $a$                      | 最大特征半径                |
| 短半轴 | $b$                      | 最小特征半径                |
| 离心率 | $e = \sqrt{1 - (b/a)^2}$ | 椭圆扁平程度，$e=0$为正圆 |
| 方向角 | $\phi$                   | 长轴方向，即像散轴方向      |
| 像散量 | $\Delta R_{FL} = a - b$  | 像散强度                    |

### 6.3 角度均匀度指标

| 指标                    | 公式                                                   | 判读标准             |
| ----------------------- | ------------------------------------------------------ | -------------------- |
| $R_{FL}$ 角度变异系数 | $CV_{R_{FL}} = \frac{\sigma_{R_{FL}}}{\bar{R}_{FL}}$ | < 2% 优秀，< 5% 良好 |
| $R_{FL}$ 最小最大比   | $\min R_{FL} / \max R_{FL}$                          | > 0.95 优秀          |
| $q$ 角度变异系数      | $CV_q = \frac{\sigma_q}{\bar{q}}$                    | < 10% 良好           |
| 周期成分幅度            | $|\tilde{R}_{FL}(n)                                    | $                    |

## 七、二维空间均匀度评估

### 7.1 直接统计指标（不依赖模型）

| 指标           | 公式                                                          | 物理意义       | 适用场景               |
| -------------- | ------------------------------------------------------------- | -------------- | ---------------------- |
| 全局变异系数   | $CV_{global} = \frac{\sigma_I}{\mu_I}$                      | 整体相对波动   | 快速评估               |
| 平顶区变异系数 | $CV_{flat} = \frac{\sigma_{I, flat}}{\mu_{I, flat}}$        | 核心区域均匀度 | **主要验收指标** |
| 非均匀度       | $NU = \frac{I_{max} - I_{min}}{I_{max} + I_{min}}$          | 峰谷相对差     | 0=完全均匀             |
| 调制深度       | $M = \frac{I_{max} - I_{min}}{I_{max} + I_{min}}$（平顶区） | 平顶起伏程度   | 干涉/曝光应用          |
| 均方根偏差     | $RMSD = \sqrt{\frac{1}{N}\sum(I_i - \bar{I})^2}$            | 绝对波动量     | 与强度量级相关         |
| 归一化RMSD     | $NRMSD = \frac{RMSD}{\bar{I}}$                              | 相对波动量     | 跨图像可比             |

### 7.2 基于FTL模型的二维指标

| 指标           | 定义                         | 计算方式                                   |
| -------------- | ---------------------------- | ------------------------------------------ |
| 逐像素相对残差 | $\epsilon(x,y)$            | 全图计算，无分箱                           |
| 残差空间标准差 | $\sigma_{\epsilon}^{(2D)}$ | 衡量残差的空间一致性                       |
| 残差空间相关性 | 相关长度$l_c$              | 半变异函数分析                             |
| 局部热点检测   | 连通域分析                   | 阈值：$|\epsilon| > 3\sigma_{\epsilon}$  |
| 局部暗点检测   | 连通域分析                   | 阈值：$|\epsilon| < -3\sigma_{\epsilon}$ |

### 7.3 频域分析

| 指标       | 定义                                          | 物理意义               |
| ---------- | --------------------------------------------- | ---------------------- |
| 功率谱密度 | $PSD(f_x, f_y) = |\mathcal{F}\{I(x,y)\}|^2$ | 空间频率能量分布       |
| 低频能量比 | $E_{low} / E_{total}$                       | 大尺度不均匀（像差）   |
| 中频能量比 | $E_{mid} / E_{total}$                       | 中尺度起伏（衍射结构） |
| 高频能量比 | $E_{high} / E_{total}$                      | 小尺度噪声（散斑）     |
| 主导频率   | $f_{peak} = \arg\max PSD(f)$                | 周期性结构周期         |

### 7.4 梯度分析

| 指标         | 公式                                                        | 物理意义               |
| ------------ | ----------------------------------------------------------- | ---------------------- |
| 梯度幅值     | $|\nabla I| = \sqrt{(\partial_x I)^2 + (\partial_y I)^2}$ | 边缘清晰度与内部平滑度 |
| 拉普拉斯能量 | $\sum |\nabla^2 I|^2$                                     | 二阶平滑度             |
| 梯度均匀度   | $CV_{|\nabla I|}$（平顶区）                               | 平顶区内部纹理         |

## 九、误差来源与不确定性分析

### 9.1 模型拟合误差

| 来源              | 影响                | 控制方法                 |
| ----------------- | ------------------- | ------------------------ |
| 初始值敏感        | 陷入局部最优        | 多初始值尝试，全局优化   |
| 过拟合（高$q$） | 虚假陡峭边缘        | 约束$q < 20$，交叉验证 |
| 欠拟合（低$q$） | 掩盖真实平顶        | 比较AIC/BIC模型选择      |
| 径向分箱噪声      | 边缘 bin 统计不稳定 | 自适应分箱（等能量 bin） |
| 角度分箱噪声      | 扇区像素不足        | 增加重叠，平滑处理       |

### 9.2 测量系统误差

| 来源                   | 影响             | 控制方法                       |
| ---------------------- | ---------------- | ------------------------------ |
| 探测器非线性           | 强度失真         | 线性度标定，限制在动态范围中段 |
| 像素响应不均匀（PRNU） | 固定图案噪声     | 平场校正                       |
| 量化噪声               | 低强度区信噪比差 | 提高 bit 深度，多次平均        |
| 光学系统像差           | 引入额外调制     | 标定系统传递函数，或纳入模型   |
| 环境振动/气流          | 时间平均模糊     | 短曝光，主动隔振               |
| 热漂移                 | 中心位置缓慢移动 | 温控，实时跟踪                 |

### 9.3 参数不确定度传递

由拟合协方差矩阵 $\Sigma$ 计算参数标准差：

$$
\sigma_{I_0} = \sqrt{\Sigma_{11}}, \quad \sigma_{R_{FL}} = \sqrt{\Sigma_{22}}, \quad \sigma_q = \sqrt{\Sigma_{33}}
$$

残差统计量的不确定度（Bootstrap估计）：

- 重复采样 $B = 1000$ 次
- 计算每次的 $P_{5\%}^{(b)}$
- 报告：$P_{5\%} \pm 1.96 \cdot \text{std}(P_{5\%}^{(b)})$

```

  │

  │     │

  │     │
  │     通过
  │     │
  ├─ 中心定位（迭代加权质心）
  │
  ├─ 全局FTL拟合 → 获取 (I₀, R_FL, q)
  │     │
  │     ├─ q < 3（非平顶）→ 报告"FTL模型不适用"
  │     │
  │     └─ q ≥ 3
  │           │
  │           ├─ R² > 0.95 → 继续
  │           │
  │           └─ R² < 0.90 → 检查模型适用性
  │
  ├─ 计算残差，提取 P₅%
  │     │
  │     ├─ P₅% > 95% → EXCELLENT，验收通过
  │     │
  │     ├─ 85% < P₅% ≤ 95% → GOOD，记录监控
  │     │
  │     ├─ 70% < P₅% ≤ 85% → FAIR，触发诊断
  │     │       │
  │     │       └─ 逐角度AD-FTL → 识别像差类型
  │     │             │
  │     │             ├─ n=2主导 → 像散，反馈SLM Z₅/Z₆补偿
  │     │             │
  │     │             ├─ n=3主导 → 彗差，调整光路中心
  │     │             │
  │     │             └─ 复杂 → 二维空间分析定位缺陷
  │     │
  │     └─ P₅% ≤ 70% → POOR，全面诊断
  │           │
  │           └─ 二维空间分析 + 频域分析 → 定位缺陷源
  │
  └─ 输出报告（参数、评级、缺陷图、建议）
```

## 附录A: 非光瞳数据融合方法

### A.1 多平面强度数据（光瞳+焦面+离焦面）

当具备多个z平面的强度图像时，可采用**强度传输方程（TIE）**进行相位恢复：

$$
-\frac{2\pi}{\lambda}\frac{\partial I}{\partial z} = \nabla_\perp \cdot (I \nabla_\perp \phi)
$$

**适用条件**：光瞳面强度近似均匀，主要相位信息来自轴向强度变化。

**数据要求**：

- 至少两个离焦面（$z = \pm \Delta z$）
- 或光瞳面+焦面组合（近似）

**输出**：波前相位 $\phi(x,y)$，可进一步分解为泽尼克系数。

**速度**：单次求解（FFT泊松求解）约 5-10 ms，远快于GS迭代。

> **注**：本方法需要额外采集离焦面图像，不纳入纯光瞳分析流程。

### A.2 哈特曼-夏克波前传感器数据

当具备哈特曼传感器时，可直接获取波前斜率，无需相位恢复：

**数据融合策略**：

- 哈特曼提供实时波前 → SLM闭环控制
- 光瞳相机提供光斑形态 → 验证闭环效果
- FTL分析提供量化指标 → 性能验收

**互补关系**：

| 数据来源 | 优势                 | 局限               |
| -------- | -------------------- | ------------------ |
| 哈特曼   | 实时、直接测相位     | 分辨率受子孔径限制 |
| 光瞳相机 | 高分辨率、验证形态   | 无直接相位信息     |
| FTL分析  | 量化均匀度、定位缺陷 | 需模型假设         |

> **注**：哈特曼数据用于闭环控制，FTL分析用于闭环后的质量验证，二者流程独立。

### A.3 SLM控制数据融合

当已知SLM加载的相位模式时，可建立**预期-实测**对比：

**应用场景**：

- SLM标定：加载已知泽尼克模式，验证实际光斑响应
- 预补偿：根据FTL分析结果，计算补偿相位
- 迭代优化：基于残差反馈，更新SLM相位

**数据流**：

```
SLM相位设计 → 光学传播 → 实测光斑 → FTL分析
     ↑___________________________________↓
              残差反馈 → 相位优化
```

> **注**：SLM控制属于主动调控环节，FTL分析属于被动诊断环节，二者通过反馈连接。

## 附录B: 算法实现参考

### B.1 核心算法复杂度

| 算法步骤     | 时间复杂度                       | 空间复杂度     | 加速策略                        |
| ------------ | -------------------------------- | -------------- | ------------------------------- |
| 预处理       | $O(N)$                         | $O(N)$       | GPU并行                         |
| 中心定位     | $O(kN)$                        | $O(N)$       | k=迭代次数，通常3-5             |
| 全局FTL拟合  | $O(mN_{bin})$                  | $O(N_{bin})$ | m=迭代次数，Levenberg-Marquardt |
| 逐角度FTL    | $O(N_{\theta} \cdot mN_{bin})$ | $O(N)$       | 扇区并行                        |
| 残差计算     | $O(N)$                         | $O(N)$       | 向量化                          |
| 频域分析     | $O(N \log N)$                  | $O(N)$       | FFT                             |
| 局部缺陷检测 | $O(N)$                         | $O(N)$       | 连通域标记                      |

$N = H \times W$ 为图像像素数。

### B.2 实时性优化建议

| 目标帧率   | 优化策略                                      | 适用场景 |
| ---------- | --------------------------------------------- | -------- |
| > 100 fps  | 固定参数FTL（预标定$q$），仅优化 $R_{FL}$ | 快速监控 |
| 30-100 fps | 全局FTL，简化预处理                           | 标准闭环 |
| < 30 fps   | 完整分析（逐角度+二维空间）                   | 精密诊断 |

### B.3 关键数值稳定性处理

| 问题                             | 处理方案                                                            |
| -------------------------------- | ------------------------------------------------------------------- |
| $x^q$ 溢出（$q$大，$x$大） | 对数域计算：$\ln I = \ln I_0 - (1+2/q)\ln(1+x^q)$                 |
| $q \to 0$ 奇异                 | 约束$q > 0.5$，或改用 $p = 1/q$ 参数化                          |
| 除零（$I_{FTL} = 0$）          | 相对残差分母加小量：$I_{FTL} + \epsilon$，$\epsilon = 10^{-10}$ |
| 空环带（无像素）                 | 插值填充或缩小分箱数                                                |
| 角度环绕（0°/360°）            | 循环延拓后平滑处理                                                  |
