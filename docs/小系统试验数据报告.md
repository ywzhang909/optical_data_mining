# 小系统试验数据 HTML 报告

本页说明 `data/小系统` 外场试验数据的报告生成脚本、产物口径与复现方式。

## 1. 脚本与产物

| 脚本 | 作用 |
|---|---|
| `scripts/xiaoxitong_report.py` | 解析试验目录，产出 `Experiment` 数据模型、试验质量补全与功率脱敏；旧版 Markdown 报告也由它生成 |
| `scripts/xiaoxitong_atm.py` | 大气通道分钟聚合、窗口/背景统计、滞后剖面，带 parquet 缓存 |
| `scripts/xiaoxitong_html.py` | 自包含 HTML 报告入口，依赖前两者，统一产出两份 HTML 与一份 CSV |

产物位于 `data/小系统/试验报告/html/`，文件名不在报告正文中出现，只列在附录：

- `01_试验数据总览.html`：批次、文件类型、距离/功率/材料、击穿时间分布；
- `02_时间与大气协同.html`：试验时间结构、大气背景、窗口与背景对比、击穿行为与环境的秩相关、滞后剖面；
- `试验窗口统计.csv`：每次试验一行，含窗口起止、各通道窗口代表值与背景差。

分钟级大气缓存位于 `data/小系统/试验报告/.cache/atm/`，按 `schema 版本 + 通道 + 日期 + 物理范围 + 源文件 size/mtime` 做指纹，源文件不变时直接命中。

## 2. 运行

在仓库根目录执行（需要 `uv sync --dev` 已完成）：

```bash
# 一次生成全部产物（推荐）
.venv/Scripts/python.exe scripts/xiaoxitong_html.py

# 只看总览，不读大气数据
.venv/Scripts/python.exe scripts/xiaoxitong_html.py --skip-atmosphere

# 大气源文件更新后强制重建缓存
.venv/Scripts/python.exe scripts/xiaoxitong_html.py --refresh-atm

# 单独检查大气通道的读取与缓存
.venv/Scripts/python.exe scripts/xiaoxitong_atm.py --days 20261009 20261010 20261012
```

主要参数：`--root`（试验数据根目录）、`--out`（报告输出目录）、`--atm-root`（大气数据根目录）、`--cache-dir`（分钟缓存目录）。默认值均指向本仓库的常规位置。

HTML 报告内联 CSS 与 SVG 图表，不依赖 matplotlib 或外部脚本，单文件可离线打开。

## 3. 数据口径

### 3.1 功率脱敏

`xiaoxitong_report.sanitize_power()` 把参数表中的具体功率数值替换为「标准功率」「低功率」或「功率（已脱敏）」。报告正文、SVG 标注与 CSV 均不含原始瓦数。

### 3.2 大气通道

只接入试验期确认有数据、且文件名符合 `ui.analysis.thermo` 发现规则的五路通道：风速、气温、相对湿度、能见度、设备 Cn²。未接入的原因：

- `r0_computed`、`aveCn2_computed`、`Absorption`：本批数据仅有表头；
- PM2.5：文件名含小数点，不符合小时分片命名；
- `Particle`：多列宽表，与长表接口不一致。

单探针先按物理范围剔除异常码（气温 1220.8、风速 122.08、Cn² 的 0 值、能见度的 0 与 75），再按分钟求跨探针中位。能见度有效区间收紧到 0.05–70 km，否则设备零点会把中位数压到 0。

### 3.3 试验窗口与背景

出光只有几秒到几十秒，分钟级环境序列在原始采集时段几乎取不到样本。因此**环境窗口 = 采集时段前后各扩 10 分钟**，原始起止时刻保留在 CSV 中备查。背景 = 同日扣除全部环境窗口、并在窗口前后各留 15 分钟保护间隔后的分钟值。代表值先按分钟跨探针取中位，再在窗口内取中位。

### 3.4 相对变化与倍率

背景近零时百分比会被分母放大到无意义（例如静风背景 0.04 m/s 对窗口 0.87 m/s 会算出 +2290%）。每个通道配置 `rel_floor`：背景低于该量级时不报百分比，改报绝对差与倍率的 log10。Cn² 的 `rel_floor` 为 1e-18，只屏蔽真正的近零背景，不会误杀正常量级的相对变化。

### 3.5 统计解释

击穿时间的文本描述（未击穿、未明显观察出、很多小孔等）按右删失处理，只对有数值的子集做统计。同步性用 Spearman 秩相关（最小样本 6），两组比较用 Mann-Whitney U；p 值未做多重比较校正，均标注为**描述性结果，不推断因果**。试验条件（距离、风机配置、待机方式）随批次成组变化，且作业时段横跨夜间与午后，任何单项相关都不能单独解释击穿差异。

## 4. 复现与验证

```bash
.venv/Scripts/python.exe -m pytest tests/test_xiaoxitong_html.py -q
.venv/Scripts/python.exe -m ruff check scripts/xiaoxitong_{atm,html,report}.py tests/test_xiaoxitong_html.py
.venv/Scripts/python.exe -m ruff format scripts/xiaoxitong_{atm,html,report}.py tests/test_xiaoxitong_html.py --check
```

`tests/test_xiaoxitong_html.py` 使用合成试验与合成大气序列，覆盖分钟边界扩展、窗口 pad、背景保护间隔、`rel_floor` 护栏、击穿删失分类、HTML 转义与脱敏、报告分节与 CSV 导出，不读取 `data/` 下的原始数据。
