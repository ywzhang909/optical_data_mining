## 光源参数-读取设备信息

### 入参

| **名称** | **描述** | **类型** | **示例** | **备注** |
|:--:|:--:|:--:|:--:|:--:|
|   date   |        历史实验日期        |  string  |  2025-07-22   |          |
| path_dir | 光强和相位文件出参存放路径 |  string  | C:\Users\liudonghua\Desktop\GDS\project\simulationAlgorithm\temporary_files\2025-07-22\张三\2025-07-19 |          |

#### 入参示例

```json
{
    "date":"2025-07-19",
    "path_dir":"C:\Users\liudonghua\Desktop\GDS\project\simulationAlgorithm\temporary_files\2025-07-22\张三\2025-07-19"
}
```

### 出参

| **名称**     | **描述**         | **类型** | **示例** | **备注**                 |
| ------------ | ---------------- | -------- | -------- | ------------------------ |
| code         | 接口状态码       | int      | 200      |                          |
| message      | 接口请求状态说明 | boolean  | true     | true(成功)   false(失败) |
| data         | 数组             | Array    |          |                          |
| -   time     | 实验时间         | String   | 14:00:00 |                          |
| -   headline | 实验标题名称     | String   | xx次实验 |                          |

说明，相位光强文件需存放在入参的"path_dir"目录中

#### 出参示例

```json
{
    "code": 200,
    "message": "true",
    "data": [
        {
            "name": "cs",
            "headline": "14:00:00"
        },
        {
            "name": "测试2",
            "headline": "13:00:00"
        }
    ]
}

```
