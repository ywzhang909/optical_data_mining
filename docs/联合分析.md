## 一、仅通过单张光瞳图片可获得的指标

以下指标**完全不需要额外硬件**，仅依赖强度图像 $I(x,y)$：

### 1.1 纯几何/能量指标（全部可获得）

| 类别   | 具体指标                      | 计算方式             | 鲁棒性                |

| 位置   | 峰值位置$(x_p, y_p)$        | 最大值搜索           | ⭐⭐ 对饱和敏感       |
| 尺寸   | 等效圆直径$D_{eq}$          | 面积等效             | ⭐⭐⭐ 高             |
| 尺寸   | FWHM / FWTM                   | 半高/十分之一高      | ⭐⭐ 受噪声影响       |
| 尺寸   | D4σ 直径                     | 二阶矩×4            | ⭐⭐ 对拖尾敏感       |
| 尺寸   | 能量约束半径$r_{95}$        | 累积能量             | ⭐⭐⭐⭐ 最鲁棒       |
| 形状   | 椭圆长短轴$(a,b)$           | 二阶矩特征值         | ⭐⭐⭐ 高             |
| 形状   | 离心率$e$                   | $\sqrt{1-(b/a)^2}$ | ⭐⭐⭐ 高             |

| 能量   | 峰值强度$I_{max}$           | 最大值               | ⭐⭐ 对饱和敏感       |

## 二、提升单张图片测量鲁棒性的预处理

针对你的光斑图像特征（渐变边缘、噪声、可能的不对称），推荐以下预处理流水线：

```python
import numpy as np
import cv2
from scipy.ndimage import gaussian_filter, median_filter
from scipy.signal import savgol_filter


def robust_pupil_preprocessing(image: np.ndarray,
                               pixel_size_um: float = 1.0,
                               bad_pixel_threshold: float = 5.0,
                               denoise_sigma: float = 1.0) -> dict:
    """
    鲁棒光瞳图像预处理流水线
  
    Returns:
        dict: 包含各阶段处理结果，便于诊断
    """
    img = np.asarray(image, dtype=np.float64)
    h, w = img.shape
    results = {'original': img.copy()}
  
    # ---------- Step 1: 坏点/热像素检测与修复 ----------
    # 用中值滤波检测异常值
    median_img = median_filter(img, size=3)
    diff = np.abs(img - median_img)
    mad = np.median(diff)  # 中位数绝对偏差
    if mad > 0:
        bad_mask = diff > bad_pixel_threshold * mad
        img_despike = img.copy()
        img_despike[bad_mask] = median_img[bad_mask]
    else:
        img_despike = img
    results['despiked'] = img_despike
  
    # ---------- Step 2: 背景估计与扣除 ----------
    # 方法A: 四角平均（适合背景均匀）
    corner_size = max(h, w) // 10
    corners = [
        img_despike[:corner_size, :corner_size],
        img_despike[:corner_size, -corner_size:],
        img_despike[-corner_size:, :corner_size],
        img_despike[-corner_size:, -corner_size:]
    ]
    bg_estimate = np.median([np.median(c) for c in corners])
  
    # 方法B: 形态学开运算估计背景（适合背景渐变）
    kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, 
                                       (max(h//20, 5), max(w//20, 5)))
    bg_morph = cv2.morphologyEx(img_despike.astype(np.float32), 
                                cv2.MORPH_OPEN, kernel)
    # 选择更保守的背景估计
    bg = min(bg_estimate, np.median(bg_morph))
  
    img_bg = np.clip(img_despike - bg, 0, None)
    results['background'] = bg
    results['background_removed'] = img_bg
  
    # ---------- Step 3: 去噪 ----------
    # 高斯滤波（保留边缘，抑制高频噪声）
    img_gauss = gaussian_filter(img_bg, sigma=denoise_sigma)
    # 非局部均值（更强去噪，但计算量大）
    # img_denoised = cv2.fastNlMeansDenoising(img_bg.astype(np.uint8), None, 10, 7, 21)
    results['denoised'] = img_gauss
  
    # ---------- Step 4: 归一化 ----------
    img_max = np.max(img_gauss)
    if img_max > 0:
        img_norm = img_gauss / img_max
    else:
        img_norm = img_gauss
    results['normalized'] = img_norm
  
    # ---------- Step 5: 有效区域掩膜 ----------
    # 基于梯度/曲率检测有效光斑区域
    grad_y, grad_x = np.gradient(img_norm)
    grad_mag = np.sqrt(grad_x**2 + grad_y**2)
  
    # 有效区域：强度高于阈值 且 梯度不过大（排除噪声尖峰）
    threshold = np.percentile(img_norm[img_norm > 0], 5)  # 5% 分位数
    valid_mask = (img_norm > threshold) & (grad_mag < np.percentile(grad_mag, 95))
    results['valid_mask'] = valid_mask
  
    # ---------- Step 6: 亚像素质心精化 ----------
    # 用有效掩膜加权计算质心
    y_idx, x_idx = np.indices((h, w))
    total = np.sum(img_norm * valid_mask)
    if total > 0:
        cx = np.sum(x_idx * img_norm * valid_mask) / total
        cy = np.sum(y_idx * img_norm * valid_mask) / total
    else:
        cx, cy = w / 2.0, h / 2.0
  
    results['centroid'] = (cx, cy)
  
    # ---------- Step 7: 径向坐标与分箱 ----------
    r = np.sqrt((x_idx - cx)**2 + (y_idx - cy)**2)
    results['radial_distance'] = r
  
    return results
```

### 关键预处理策略总结

| 问题         | 预处理                  | 原理                   |
| ------------ | ----------------------- | ---------------------- |
| 坏点/热像素  | 中值滤波检测 + 替换     | MAD 异常值检测         |
| 背景不均匀   | 形态学开运算 / 四角估计 | 大尺度结构为背景       |
| 高频噪声     | 高斯滤波 / 非局部均值   | 频域低通               |
| 光斑边缘模糊 | 梯度约束掩膜            | 保留真实边界，排除噪声 |
| 亚像素定位   | 加权质心 + 迭代精化     | 一阶矩天然亚像素       |
| 饱和像素     | 饱和检测 + 降权         | 饱和区信息不可信       |

## 三、光瞳 + 光轴图片 → 快速波前还原

这是核心问题。已知条件：

- **光瞳面（Pupil plane）**：振幅分布 $|A(x,y)|^2$（即你的光瞳图片）
- **光轴/焦面（Focal plane）**：强度分布 $I_f(u,v)$（远场光斑）

这正是一个**相位恢复（Phase Retrieval）**问题。经典 GS 算法慢是因为需要多次 FFT 迭代，但存在更快的替代方案：

### 3.1 比 GS 快的算法对比

| 算法                                        | 速度                 | 原理                  | 适用场景     |
| ------------------------------------------- | -------------------- | --------------------- | ------------ |
| **误差减少（ER）**                    | 与 GS 类似           | 交替投影              | 简单场景     |
| **混合输入输出（HIO）**               | 与 GS 类似           | 引入反馈参数$\beta$ | 有支撑约束   |
| **HIO + 过采样平滑**                  | 略快                 | 加速收敛              | 过采样数据   |
| **TIE（强度传输方程）**               | ⚡**最快**     | 单步微分解析          | 近轴、小像差 |
| **基于深度学习的相位恢复**            | ⚡**单次前向** | 神经网络端到端        | 有训练数据   |
| **基于泽尼克模式的参数化拟合**        | ⚡**极快**     | 低维参数搜索          | 低阶像差主导 |
| **基于曲率传感（Curvature Sensing）** | ⚡**快**       | 两平面强度差→相位    | 需要离焦面   |

### 3.2 推荐方案：TIE + 泽尼克参数化（最快实用组合）

对于你的 SLM + 哈特曼系统，**TIE（Transport of Intensity Equation）** 是最快的解析方法：

$$
-\frac{2\pi}{\lambda}\frac{\partial I}{\partial z} = \nabla_\perp \cdot \left(I \nabla_\perp \phi\right)
$$

若光瞳面强度均匀（$I \approx const$），简化为泊松方程：

$$
\nabla^2 \phi = -\frac{2\pi}{\lambda I}\frac{\partial I}{\partial z}
$$

**实现步骤**：

```python
import numpy as np
from scipy.fft import fft2, ifft2, fftfreq


def tie_phase_retrieval(pupil_intensity: np.ndarray,
                        focal_intensity: np.ndarray,
                        focal_distance: float,
                        wavelength: float,
                        pixel_size: float,
                        regularization: float = 1e-6) -> np.ndarray:
    """
    基于 TIE 的相位恢复（光瞳面 + 焦面强度）
  
    假设：光瞳面强度近似均匀，主要相位信息来自焦面变化
  
    Args:
        pupil_intensity: 光瞳面强度 (H, W)
        focal_intensity: 焦面强度 (H, W)
        focal_distance: 光瞳到焦面的距离 [m]
        wavelength: 波长 [m]
        pixel_size: 像素物理尺寸 [m]
        regularization: 正则化参数
  
    Returns:
        phase: 恢复的波前相位 [rad]
    """
    # 归一化
    I_pupil = np.asarray(pupil_intensity, dtype=np.float64)
    I_focal = np.asarray(focal_intensity, dtype=np.float64)
  
    # 计算轴向强度导数（有限差分近似）
    # dI/dz ≈ (I_focal - I_pupil) / focal_distance
    # 注意：实际应使用两个离焦面，这里用焦面-光瞳面近似
    dIdz = (I_focal - I_pupil) / focal_distance
  
    # 平均强度（TIE 中的 I）
    I_avg = (I_pupil + I_focal) / 2.0
    I_avg = np.clip(I_avg, np.max(I_avg) * 0.01, None)  # 避免除零
  
    # 构建泊松方程右侧
    rhs = - (2 * np.pi / wavelength) * dIdz / I_avg
  
    # 频域求解泊松方程
    H, W = rhs.shape
    fx = fftfreq(W, pixel_size)
    fy = fftfreq(H, pixel_size)
    FX, FY = np.meshgrid(fx, fy)
  
    # 拉普拉斯算子的频域表示
    laplacian_freq = - (2 * np.pi)**2 * (FX**2 + FY**2)
    laplacian_freq[0, 0] = 1.0  # 避免 DC 除零
  
    # 正则化
    laplacian_freq = np.where(
        np.abs(laplacian_freq) < regularization,
        regularization * np.sign(laplacian_freq),
        laplacian_freq
    )
  
    # 求解
    rhs_fft = fft2(rhs)
    phase_fft = rhs_fft / laplacian_freq
    phase = np.real(ifft2(phase_fft))
  
    # 去除 piston
    phase = phase - np.mean(phase)
  
    return phase


def zernike_fit_phase(phase: np.ndarray,
                      n_modes: int = 15,
                      aperture_radius: Optional[float] = None) -> tuple:
    """
    将恢复的相位拟合为泽尼克模式系数
  
    这进一步压缩信息，便于自适应光学控制
    """
    from aotools import zernike
  
    H, W = phase.shape
    if aperture_radius is None:
        aperture_radius = min(H, W) / 2.0
  
    # 生成圆形孔径掩膜
    y, x = np.indices((H, W))
    cy, cx = H / 2.0, W / 2.0
    r = np.sqrt((x - cx)**2 + (y - cy)**2)
    mask = r <= aperture_radius
  
    # 生成泽尼克基函数
    zernike_basis = zernike.zernike_noll(n_modes, H, norm=True)
  
    # 最小二乘拟合
    # Z: (n_modes, H*W), phase_vec: (H*W,)
    Z = np.array([z[mask].flatten() for z in zernike_basis])
    p_vec = phase[mask].flatten()
  
    # 正规方程
    coeffs = np.linalg.lstsq(Z.T, p_vec, rcond=None)[0]
  
    # 重构相位
    phase_fitted = np.zeros((H, W))
    for i, c in enumerate(coeffs):
        phase_fitted += c * zernike_basis[i]
  
    return coeffs, phase_fitted, mask
```

### 3.3 更快的方案：深度学习端到端

如果已有大量 SLM 加载已知相位 → 同时采集光瞳图 + 焦面图的数据对，可以训练一个 U-Net：

```python
import torch
import torch.nn as nn


class PhaseNet(nn.Module):
    """
    端到端相位恢复网络
    输入：光瞳强度 (1, H, W) + 焦面强度 (1, H, W) → 拼接为 (2, H, W)
    输出：波前相位 (1, H, W)
    """
    def __init__(self, in_channels=2, out_channels=1, base_channels=64):
        super().__init__()
        # U-Net 编码器
        self.enc1 = self._conv_block(in_channels, base_channels)
        self.enc2 = self._conv_block(base_channels, base_channels * 2)
        self.enc3 = self._conv_block(base_channels * 2, base_channels * 4)
      
        self.pool = nn.MaxPool2d(2)
      
        # 解码器
        self.up2 = nn.ConvTranspose2d(base_channels * 4, base_channels * 2, 2, stride=2)
        self.dec2 = self._conv_block(base_channels * 4, base_channels * 2)
        self.up1 = nn.ConvTranspose2d(base_channels * 2, base_channels, 2, stride=2)
        self.dec1 = self._conv_block(base_channels * 2, base_channels)
      
        self.out = nn.Conv2d(base_channels, out_channels, 1)
  
    def _conv_block(self, in_ch, out_ch):
        return nn.Sequential(
            nn.Conv2d(in_ch, out_ch, 3, padding=1),
            nn.BatchNorm2d(out_ch),
            nn.ReLU(inplace=True),
            nn.Conv2d(out_ch, out_ch, 3, padding=1),
            nn.BatchNorm2d(out_ch),
            nn.ReLU(inplace=True)
        )
  
    def forward(self, x):
        e1 = self.enc1(x)
        e2 = self.enc2(self.pool(e1))
        e3 = self.enc3(self.pool(e2))
      
        d2 = self.up2(e3)
        d2 = self.dec2(torch.cat([d2, e2], dim=1))
        d1 = self.up1(d2)
        d1 = self.dec1(torch.cat([d1, e1], dim=1))
      
        return self.out(d1)


# 训练数据生成（SLM 已知相位作为 GT）
def generate_training_data(slm, camera_pupil, camera_focal, n_samples=1000):
    """
    用 SLM 加载随机泽尼克相位，采集光瞳+焦面图对
    """
    dataset = []
    for _ in range(n_samples):
        # 随机泽尼克系数
        coeffs_gt = np.random.randn(15) * 0.5  # 单位：rad
        phase_gt = zernike_reconstruct(coeffs_gt, 512)
      
        # SLM 加载
        slm.set_phase(phase_gt)
      
        # 采集
        I_pupil = camera_pupil.capture()
        I_focal = camera_focal.capture()
      
        dataset.append((I_pupil, I_focal, phase_gt))
  
    return dataset
```
